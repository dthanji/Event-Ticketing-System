Day 8 Reflection
The most difficult concept in this course was understanding how distributed systems maintain correctness while handling large amounts of traffic at the same time. Initially, I focused more on adding features and improving performance, but I found it challenging to understand how systems ensure that data remains accurate when many users are interacting with the application simultaneously. I overcame this by studying real-world examples such as ticket-booking platforms, banking systems, and e-commerce websites. These examples helped me understand the importance of transactions, database constraints, and consistency.

Based on the feedback I received on my capstone project, I would improve the scalability aspects of the design. While my original solution met the functional requirements, I did not fully consider how the system would perform during periods of extremely high demand. Learning about load balancers, caching, queues, and horizontal scaling helped me recognize areas where the design could be strengthened.

The next topic I plan to learn is cloud architecture, particularly Microsoft Azure services. I want to gain a better understanding of services such as Azure Load Balancer, Azure SQL Database, Azure Cache for Redis, and Azure Service Bus. Learning these technologies will help me design more scalable and reliable applications in the future.
